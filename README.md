# saycheer-website
> Version 1.0 — 2026-11-09

Public website for **SayCheer Photo Booth by Janishammer** (planned address: https://saycheer.janishammer.com/), English and Thai.

- Stand-alone site with its own look: no brand navbar or footer, **no injector** (HTML-5 exclusion in janishammer-central).
- Static files, Cloudflare Pages auto-deploy from `main` (DEP-3), no build command.
- Governance lives in the janishammer-central repo; this repo carries a seed `CLAUDE.md` only.
- Images only via Cloudinary (CONT-4, cloud `dfiomi0lb`); no image files are committed here.
- Status: skeleton, **unindexed** (`noindex`), placeholder pages only. See `PROJECT_STATE.md`.
